## Por que MDX?

Escolhi MDX porque permite escrever Markdown normal com componentes React interativos. Isso traz muitas possibilidades:

- Códigos com syntax highlighting
- Componentes customizados
- Diagramas interativos
- Exemplos ao vivo

}
